# Security policy

This pre-alpha is a local, offline learning game. It processes no personal data and contains no network, save-file, plug-in, shell or authentication surface.

Report suspected vulnerabilities through GitHub private vulnerability reporting when enabled; otherwise open an issue without exploit details and ask the maintainer for a private channel. Do not include secrets or personal data in reports.

Supported version: only the latest commit on `main` during pre-alpha. Future file, mod, telemetry or multiplayer features require a new threat model before implementation.
