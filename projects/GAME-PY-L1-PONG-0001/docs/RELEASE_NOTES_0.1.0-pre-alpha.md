# Pong 0.1.0-pre-alpha — release notes

This is an evidence-bearing pre-alpha, not a release candidate.

Included: deterministic two-player Pong rules, Tkinter UI adapter, headless tests, Python zipapp build, checksum manifest, Windows import smoke, and traceability passports.

Run the source with `python -m pong.app`, or build with `python scripts/build_zipapp.py` and run `python dist/father-pong.pyz`. Use `--self-check` for a non-GUI product check.

Known limits: no standalone executable; Python 3.11+ with Tkinter is required; real Windows window, controls, frame pacing, and visuals are awaiting operator evidence. No screenshots or GIFs are asserted yet.
