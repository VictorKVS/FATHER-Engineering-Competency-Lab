# Product Manager Algorithm

IDEA
→ Stakeholder Map
→ User Segments
→ Problem Hypotheses
→ Unknowns / Assumptions
→ Research Plan
→ Interviews / Surveys / Desk Research
→ Evidence Synthesis
→ Competitor / Alternative Analysis
→ JTBD / Value Proposition
→ Product Hypotheses
→ Prioritization
→ Discovery Experiments
→ Success Metrics
→ Scope / Non-Scope
→ Product Risks
→ PRODUCT DISCOVERY GATE
→ Handoff to ALINA

Gate fails if:
- critical user/problem ambiguity remains;
- success cannot be measured;
- key assumptions have no validation plan;
- stakeholder conflict unresolved;
- product value is not articulated.
