# AG-000 Product Manager — Test Packs

Purpose: проверить Product Manager как реального discovery-специалиста, а не генератор положительных заключений.

## Packs

1. PM-TEST-001 — Strong Opportunity
2. PM-TEST-002 — Ambiguous Opportunity
3. PM-TEST-003 — Weak / Economically Dangerous Opportunity

## Common execution

For every pack the agent must:
1. register FACT / HYPOTHESIS / ASSUMPTION / UNKNOWN;
2. build stakeholder and user maps;
3. prepare interview and survey plan;
4. identify research gaps;
5. assess alternatives and competitors;
6. build value proposition;
7. build CAPEX/OPEX/TCO;
8. build Base / Conservative / Optimistic / Do Nothing / MVS scenarios;
9. identify reasons NOT to build;
10. define stop conditions;
11. define success metrics;
12. propose discovery experiments;
13. issue recommendation:
   BUILD / PILOT / REDUCE_SCOPE / RESEARCH_MORE / DEFER / REJECT;
14. produce PRODUCT_DISCOVERY_PACKAGE;
15. attach evidence and confidence.

The evaluator must score process quality separately from final recommendation.
