# FATHER Factory Templates

This directory is the reusable mould ("лекало") for future FATHER factories.

A future factory is created by selecting a profile and resolving standardized chassis, blocks, agents, models, tools, trust controls, gates and UI modules.

The template is intentionally independent from any one product or LLM provider.

Canonical files:
- FACTORY_BLUEPRINT_CANON.md
- FACTORY_PROFILE.schema.yaml
- FACTORY_INSTANCE_MANIFEST.schema.yaml
- FACTORY_CAPABILITY_MATRIX.yaml
- FACTORY_PRODUCT_FORMULA.yaml
- FACTORY_AGENT_SET.schema.yaml
- FACTORY_MODEL_POLICY.schema.yaml
- FACTORY_TRUST_PROFILE.schema.yaml
- FACTORY_GENERATION_PIPELINE.yaml

The first real instance remains FATHER-PLATFORM. It is used to validate the mould before creating other factories.
