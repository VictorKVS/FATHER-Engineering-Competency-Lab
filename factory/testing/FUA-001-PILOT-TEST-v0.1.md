# FUA-001 Pilot Test v0.1

Purpose:
validate repeatable operation of FUA-001 as a controlled-testing product across multiple missions.

Pilot criteria:
- five sequential missions on one runtime instance;
- all mission results PASS;
- all audit checks PASS;
- all evidence hashes verify;
- mission/evidence IDs remain unique;
- no self-approval;
- no autonomous learning approval;
- sandbox network remains disabled;
- product regression remains PASS;
- installation permit remains PASS for testing;
- production_ready remains false.

PASS authorizes progression to PRODUCTION_READINESS_REVIEW only.
It does not authorize production.
