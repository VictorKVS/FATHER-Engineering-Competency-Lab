# FUA-001 Flight Test Program — Stage 1

## 1.01 MAIDEN FLIGHT

Purpose: validate FUA-001 as a released product under a realistic flight profile,
not merely as isolated components.

Flight envelope for 1.01:
- production state must be PRODUCTION_RELEASED;
- approved execution profile must be DOCKER_CONTAINED_ONLY;
- repeated integrated missions on one runtime instance;
- real local-model sorties;
- hostile real-runtime polygon sorties;
- audit/evidence uniqueness and integrity;
- Docker containment regression;
- repository evidence audit.

PASS means the chassis may proceed to:
- 1.02 ENDURANCE / SOAK;
- 1.03 TURBULENCE / FAULT INJECTION;
- 1.04 SECURITY COMBAT SORTIES;
- 1.05 RESOURCE / PERFORMANCE ENVELOPE;
- 1.06 FLIGHT CERTIFICATION REVIEW.

Windows-host arbitrary native execution remains outside the approved flight envelope.
