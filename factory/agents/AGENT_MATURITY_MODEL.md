# FATHER Agent Maturity Model

M0 — IDEA
M1 — ROLE DEFINED
M2 — STANDARD PACKAGE DEFINED
M3 — WORKING IMPLEMENTATION / DISTRIBUTED ASSETS
M4 — WORKING PROTOTYPE WITH TESTS AND EVIDENCE
M5 — FACTORY INTEGRATED
M6 — POLYGON VERIFIED
M7 — PRODUCTION PROVEN

An agent is not considered mature because a prompt exists.

Required maturity dimensions:
- role clarity
- prompt quality
- algorithm quality
- RAG coverage
- knowledge quality
- input/output contracts
- API handoff
- tools/runtime
- evals
- tests
- security
- evidence
- experience
- integration
