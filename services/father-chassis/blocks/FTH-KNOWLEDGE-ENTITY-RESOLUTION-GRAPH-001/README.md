# Knowledge Entity Resolution / Graph
Block ID: FTH-KNOWLEDGE-ENTITY-RESOLUTION-GRAPH-001

Purpose: resolve typed K5 entities into stable graph nodes and materialize evidence-backed graph edges without losing extraction lineage.

Scope:
- entity resolution policy;
- canonical graph node identity;
- merge/no-merge decisions;
- conflict handling;
- graph edge construction;
- evidence lineage;
- deterministic graph snapshot hash.

Non-goals:
- probabilistic global record linkage;
- graph database deployment;
- embeddings;
- inferred/derived relations;
- temporal reasoning;
- graph query API.

Current target: B6 DEVELOPMENT READY before implementation.
