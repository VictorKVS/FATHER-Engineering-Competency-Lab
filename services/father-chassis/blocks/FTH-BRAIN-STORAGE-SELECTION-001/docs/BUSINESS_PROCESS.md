# BUSINESS_PROCESS

## Trigger
A Brain Package or product recipe requires a storage architecture.

## Flow
1. Capture workload and deployment constraints.
2. Load qualified abstract Storage Profiles.
3. Reject profiles that violate hard constraints.
4. Rank remaining profiles by minimal sufficient complexity/resources.
5. Produce human-readable selection reasons.
6. Produce human-readable rejection reasons for alternatives.
7. Pass selected abstract profile to technology/adaptor selection and benchmark stages.

## Business outcome
A repeatable architecture recommendation instead of manual vendor preference.

## Non-goal
This block does not select PostgreSQL/Qdrant/Neo4j by marketing assumptions.
