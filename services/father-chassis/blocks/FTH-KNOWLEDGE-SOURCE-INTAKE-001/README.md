# Knowledge Source Intake
Block ID: FTH-KNOWLEDGE-SOURCE-INTAKE-001

Purpose: convert an external source candidate into a deterministic, traceable SourceIntakeRecord before any parsing, chunking or indexing occurs.

Scope:
- source identity;
- source class;
- locator;
- declared rights/access state;
- content fingerprint/hash;
- version/effective/publication dates;
- intake status;
- handoff to legal/access and provenance validation.

Non-goals:
- parsing source content;
- extracting entities;
- building embeddings/indexes;
- deciding final legal admissibility;
- qualifying the KB release.

Current target: B6 DEVELOPMENT READY before implementation.
