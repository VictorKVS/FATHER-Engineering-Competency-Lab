# Knowledge Structural Parser
Block ID: FTH-KNOWLEDGE-STRUCTURAL-PARSER-001

Purpose: transform an APPROVED, provenance-bound source into deterministic structural document units while preserving source traceability.

Scope:
- document/page/section/block structure;
- text block boundaries;
- structural locators;
- source hash/provenance binding;
- parser diagnostics;
- deterministic parse output.

Non-goals:
- semantic chunk optimization;
- embeddings;
- entity/relation extraction;
- OCR as default path;
- KB qualification.

Current maturity: B9 QUALIFIED by G7 K3 Structural Parser evidence.
