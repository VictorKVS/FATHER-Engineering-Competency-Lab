# Qualified KB Admission
Block ID: FTH-FACTORY-QUALIFIED-KB-ADMISSION-001

Purpose: admit a factory agent to a stage only when every knowledge base required by its role is bound to a qualified, versioned knowledge release.

Scope:
- KB release identity/version/hash;
- source-set provenance references;
- retrieval qualification evidence;
- stage/agent required-KB resolution;
- fail-closed admission;
- workflow evidence binding.

Non-goals:
- source ingestion/parsing/chunking implementation;
- vector database implementation;
- full Knowledge Factory pipeline;
- copyright/source-rights automation.

Current target: B6 DEVELOPMENT READY before implementation.
