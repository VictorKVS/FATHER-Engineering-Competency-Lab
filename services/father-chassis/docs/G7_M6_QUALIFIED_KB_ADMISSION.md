# G7 M6 — Qualified KB Admission

M6 qualifies knowledge-release admission at the engineering workflow boundary.

Acceptance:
- Ruff/static correctness;
- full father-chassis regression;
- qualified release admits;
- missing release blocks;
- unqualified release blocks;
- missing provenance blocks;
- missing retrieval evidence blocks;
- exact release ID/hash/evidence trace preserved;
- strict KB mode without gate fails closed;
- restart preserves KB admission trace;
- workflow snapshot schema v4 is used.

M6 does not qualify the future Knowledge Factory ingestion/indexing pipeline itself.
