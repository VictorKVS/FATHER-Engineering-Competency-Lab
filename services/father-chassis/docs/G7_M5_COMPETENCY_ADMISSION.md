# G7 M5A / M5 Qualification

## M5A Trust Integration Packaging
Proves separate Trust/chassis installation, public API compatibility, independent Trust tests, chassis tests and cross-package evaluator execution.

## M5 Competency Admission
Proves strict workflow admission:
- qualified agent admitted;
- under-qualified agent blocked;
- missing evidence blocked;
- Trust qualification/evidence references preserved;
- strict competency mode without gate fails closed;
- Trust tests and chassis regression both pass.

Neither gate proves evidence freshness, revocation, signatures or persistent Trust ledger integration.
