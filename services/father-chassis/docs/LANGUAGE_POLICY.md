# Documentation Language Policy / Политика языка документации

## Русский

Для всех ключевых материалов FATHER обязательна русская версия:

- README;
- архитектура;
- инструкции по запуску;
- qualification reports;
- release notes;
- описание тестов;
- BOM / reuse reports;
- эксплуатационные инструкции;
- документация по безопасности.

Английская версия ведётся параллельно для совместимости с международными инструментами, разработчиками и экосистемой GitHub.

## English

All key FATHER documentation must have a full Russian version.

English documentation is maintained in parallel for tooling compatibility, international collaboration, GitHub ecosystem integration and external technical communication.

Neither language version should be a materially reduced substitute for the other.
