# Релиз FATHER Chassis 0.6.0

## Результат

**37/37 автоматических тестов пройдено.**

## Что доказано в текущей среде

- HTTP API запускается через FastAPI;
- liveness/readiness отражают состояние аварийного стопа;
- документы загружаются через `/ingest`;
- запрос проходит через runtime и возвращает evidence;
- audit сохраняется на диск и читается после повторного открытия БД;
- audit доступен по `trace_id` через API;
- список моделей и health доступны через API;
- Dockerfile и Docker Compose подготовлены;
- конфигурация позволяет подключить OpenAI-compatible локальную LLM.

## Что ещё не считаем доказанным

G3 не считаем полностью закрытым до запуска на целевой Windows-машине. Нужно отдельно проверить Docker Desktop, PostgreSQL/pgvector, Redis, локальную LLM, сетевые маршруты и перезапуск контейнеров.
