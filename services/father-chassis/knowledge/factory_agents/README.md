# Factory Agent Knowledge Bases

This directory defines what each factory-agent knowledge base must contain. It intentionally stores contracts and metadata, not copyrighted source files.

Planned KBs:

- KB-BUSINESS-ANALYSIS
- KB-SYSTEM-ANALYSIS
- KB-ALGORITHMS
- KB-ARCHITECTURE
- KB-TEST-ENGINEERING
- KB-SOFTWARE-ENGINEERING
- KB-DEVSECOPS
- KB-QUALIFICATION-EVIDENCE

For every KB, populate sources through Knowledge Factory with source/version/provenance/hash/locator metadata. Raw copyrighted books or proprietary documents must not be committed here unless repository rights explicitly allow it.
