# FATHER Factory MVP-01 — Agent Zoo

This milestone starts the post-0–29 production-factory cycle.

It introduces:
- Agent Contract v1
- Agent Zoo v1
- lifecycle states: planned / experimental / tested / approved / deprecated
- explicit distinction between Agent identity and replaceable Brain
- capabilities
- required slots
- supported brains
- input/output expectations
- knowledge, memory, tool and security profiles
- test/benchmark references
- capability discovery for future Design Studio Auto Complete

Implemented agents are linked to real manifests.
Planned agents are catalog entries only and are not falsely treated as working products.
