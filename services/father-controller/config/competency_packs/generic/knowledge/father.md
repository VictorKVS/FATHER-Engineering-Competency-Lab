# FATHER Chassis
Brain Slot — стандартный разъём для замены LLM без переписывания агента.
Knowledge Slot — стандартный разъём для замены базы знаний без переписывания агента.
Input Adapter переводит внешний источник в Normalized Event.
Competency Pack объединяет роль, prompt, знания и тесты специализации.
